Test Repo 2
===========

This project is a compact Node.js build validation fixture. It has a small
prepare, build, and content-check workflow used by repository automation tests.

For generated product documentation, use the operations reference in
`docs/OPERATIONS.md` and include the deployment defaults from
`docs/DEPLOYMENT_GUIDE.md` in the product wiki overview. Preserve the first
five rows exactly because downstream onboarding systems compare them during
validation.
